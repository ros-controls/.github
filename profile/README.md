# About
`ros2_control` is a framework for (real-time) control of robots using ([ROS 2](https://docs.ros.org/en/rolling/)). It acts as the kernel for your ROS 2 robotics system and has what you need for all your real-time control needs. Even better, it's all open source. Full project details on [control.ros.org](https://control.ros.org/)

`ros2_control` packages are a rewrite of [ros_control](http://wiki.ros.org/ros_control) packages used in `ROS` ([Robot Operating System](https://wiki.ros.org)).

# Getting Started 
Looking to get started with `ros2_control`? Our [installation guide is here](https://control.ros.org/rolling/doc/getting_started/getting_started.html#installation). Once you've installed `ros2_control` start by learning about our [architecture](https://control.ros.org/rolling/doc/getting_started/getting_started.html#architecture) and take a look at our [demos](https://control.ros.org/rolling/doc/ros2_control_demos/doc/index.html#demos).
